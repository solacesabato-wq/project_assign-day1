# Customer API Extraction Project

## Project Overview
This project extracts customer records from a REST API,
flattens nested JSON responses and exports clean customer
data into a CSV file for analytics consumption.

## Business Problem
Duka Connect requires customer directory data from a
partner REST API in a structured format that the
analytics team can easily consume.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- Requests
- REST API
- JSON
- Git & GitHub

## Project Workflow
1. Connect to the REST API.
2. Extract customer records.
3. Flatten nested JSON.
4. Clean and transform customer data.
5. Convert the records into a Pandas DataFrame.
6. Export the final dataset to CSV.

## Expected Output
A clean CSV file containing structured customer records
ready for analytics consumption.
